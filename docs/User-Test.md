# User Testing Prototype
Each task was given to 5 different individuals, the rating and notes are all the generalised feedback for the prototype

| Task | Completed Unaided | Ease Rating 1-5 (rounded average) | General Notes                                                                                                                                                                                                      |
| --- | --- |-----------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Register and Login | Yes | 5                                 | Input fields have labels that help the user register and the necessary information is straight forward. User is redirected straight to login making the process easier                                             |
| Create a profile | Yes | 4                                 | Straightforward prompts, some specific selections so it's harder to input the wrong information                                                                                                                    |
| Log a workout with two exercises | Yes | 4                                 | Excercises aren't generated automatically so users have to input them however, categories are dropdowns for ease                                                                                                   |
| Schedule a workout for tomorrow with a reminder | Yes | 4                                 | Every input is a dropdown box making the selections visible for users, the labels also perfectly explain what to input                                                                                                                                                                                                                   |
| Find a past workout in history and edit it | Yes | 2                                 | Workout History is hard to navigate because the individual exercises that appear is too much to look at, it was recommended that the exercises get grouped into sessions rather than just all of the individual exercises |
| Log a meal and find today's total on dashboard | Yes | 4                                 | Meal macros have to be manually inputted, but labels explain well and it shows up on the dashboard once logged                                                                                                                                                                                                               |
| Find your progress chart | Yes | 4                                 | Progress tab is labelled correctly, users can access the chart from anywhere on the app. It clearly shows performance metrics                                                                                                                                                                                                        |
